# Daily Planner (JavaFX)
This is a desktop application that is built with JavaFX that helps its user manage their daily tasks, organize categories or filters, and also visualize their scedule via a clean interface easily used.

# Features
- You're able to add, edit, or even delete tasks as you please
- You can organize tasks by a specific category
- You are able to view your tasks in a simple daily layout
- There is CSS styling to help enhance a modern UI

# What is it built with?
- JavaFX
- CSS for styling purposes
- Java 22

# How do you run this application?
1. First, download the project files given
2. Open the project in an IDE of your choosing (I use Eclipse and VSCode)
3. Set your JavaFX SDK path in the run configurations section
4. All you need to do is "Run" DailyPlannerApp.java
